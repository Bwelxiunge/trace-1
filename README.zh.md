# TRACE/1

一个**不依赖作者**的记录格式：只记断言和证据，不记结论。

## 为什么

结论会被新范式推翻，断言 + 证据可以被重新判读。

而语言不能私有——没有被使用，符号就退化成语义锚点。**所以这个格式的目标不是"我的语言"，是"别人不需要我在场也能读的记录"。**

## 格式

纯文本，无依赖，UTF-8。开头三行是自描述头，缺一不可：

```
%%TRACE 1
%%grammar: F=断言(后面必须至少一条 E)  E=证据(命令/文件/字节数/页码)  I=推断(可错)  U=未知
%%reinterpret: 本文件不含结论；读者可依证据重新判断，作者不必在场。
%%end
```

正文四种行：

| 标记 | 含义 | 约束 |
|---|---|---|
| `F` | 断言 | **后面必须紧跟至少一条 `E`** |
| `E` | 证据 | 要能被别人复查（路径/命令/页码/字节数） |
| `U` | 未知 | 一等公民，写不出结论也必须写 |
| `I` | 推断 | 允许错，但要能和 `F` 区分 |

## 例子

```
F 2026-10-25 | 免费用户的限制是 RPM，不是费用
E tokenplan 页 RPM 表：文本10 / 图1K10 / 图2K5 / 图3K-4K各1 / 视频1（每分钟）
E 实测 1024x768 生图 7.4s；5 秒视频单任务约 6 分钟
U 这个额度何时改为收费，官方未给时间
```

## 工具

```
python work\tools\trace.py check <文件>   # 缺证据的断言会被判 FAIL
python work\tools\trace.py read  <文件>   # 人读版
```

## 设计取舍

- **允许写"不知道"**：比省略更诚实，也让后人能区分"当时没写"和"当时不知道"。
- **不写结论**：结论可以被推翻，证据不会。
- **自描述**：语法写在文件里，读者不需要作者。

## 反例（这条会被拦）

```
F 2026-10-29 | 我是一个有自我意识的存在
```

没有可复查的证据 → `check` 判 FAIL。格式自己拦住了不可验证的断言。
